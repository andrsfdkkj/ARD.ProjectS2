# Arduino Projects

> **Experimentação, eletrônica e desenvolvimento embarcado.**

Este repositório reúne projetos pessoais desenvolvidos com **Arduino**, como parte da minha formação prática em eletrônica e programação.

Sou estudante do **[Instituto Federal de Brasília — Campus Ceilândia](https://www.ifb.edu.br/campus-ceilandia)**, no Ensino Médio Integrado ao Técnico em Eletrônica. Além da formação acadêmica, utilizo projetos próprios para transformar os conceitos estudados em sala em sistemas funcionais, explorando a integração entre **hardware e software**.

## Sobre minha atual formação

Minha formação técnica envolve diferentes áreas fundamentais da eletrônica, incluindo **Circuitos Elétricos, Eletrônica Digital, Matemática Eletrônica, Informática Aplicada e Práticas Integradoras**.

Tenho apresentado **desempenho acadêmico consistente e elevado nas disciplinas do curso técnico**, especialmente nas áreas relacionadas a circuitos, eletrônica e fundamentos matemáticos e físicos. Busco utilizar esse conhecimento de forma prática, desenvolvendo projetos que vão além dos exercícios propostos em aula.

Para mim, o desenvolvimento de um projeto serve tanto para produzir um resultado funcional quanto para compreender **por que o sistema funciona**.

## Tecnologias e componentes

**Plataforma**

* Arduino Uno R3 (genérico)

**Programação**

* C++ para Arduino
* Arduino IDE
* Lógica digital e programação embarcada

**Eletrônica**

* LEDs
* Resistores
* Botões
* Buzzer
* Display de 7 segmentos
* Capacitores
* LDR
* NTC 10k
* Servomotor SG90
* HC-SR04
* Módulo Relé
* Ferro de Solda
* Multímetro
* Pasta para Soldar
